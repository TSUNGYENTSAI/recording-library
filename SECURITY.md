# Privacy and security

The repository must not contain private audio, transcripts, credentials, models or Library databases. Normal transcription and naming are offline subprocesses; the explicit model/runtime setup step connects to upstream package/model providers.

Do not include sensitive recordings or tokens in a public issue. If a problem requires sensitive details, first open a minimal issue asking the maintainer for a private reporting route. Never post the sensitive payload while waiting for that route.

This is an early preview, not an audited security product. No cloud service, account backend, telemetry or remote command execution interface is implemented.
